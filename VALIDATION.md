# Контейнерная проверка

Дата проверки 13 ноября 2026.

[Успешный прогон GitHub Actions](https://github.com/lesopylka/BigDataFlink/actions/runs/43435510128).

Проверены Maven-сборка, загрузка 10000 сообщений Kafka в PostgreSQL, повторная доставка без дублей, свежие checkpoints и перезапуск JobManager и TaskManager.

Контрольные значения после каждого расчета или повторной доставки

- 10000 уникальных продаж
- 54623 единицы товара
- Сумма 2529852.12

Исходные файлы содержат по 1000 строк, всего 10 CSV. Сборка и проверка выполняются на чистом Ubuntu runner через Docker Compose, без подмены сервисов. Команды воспроизводятся из [.github/workflows/integration.yml](.github/workflows/integration.yml).

Второй запуск producer увеличивает Kafka log end offset до 20000, количество фактов остается 10000. После перезапуска Flink проверка ожидает новый checkpoint и чтение всех 20000 сообщений. Позиция Kafka и PostgreSQL проверяются после фактического завершения чтения.

Исправлены конфликт jackson-core/jackson-databind и повторная загрузка PostgreSQL-драйвера при рестарте. Доставка остается at-least-once с идемпотентной записью фактов, распределенная exactly-once транзакция не заявляется.
